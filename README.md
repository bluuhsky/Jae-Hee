# Jae Hee — Blue Discord Profile

A standalone HTML/CSS/JS personal profile. No framework or build step is required.

## Run
Open `index.html` in a browser, or upload the whole folder to GitHub Pages.

## Customize
- Edit `CONFIG` in `script.js` for artists, songs, anime, games and social links.
- Replace `assets/background.mp4` with your own background video.
- Replace the avatar/banner URLs in `CONFIG`.
- The anime cards intentionally use lightweight generated placeholders so the site works without guessing image URLs. You can replace each `.anime-cover` with your own `<img>` later.
- The music player is UI-only and does not include copyrighted audio.

## GitHub Pages
Create a repository, upload the files/folder contents, then enable Pages from Settings → Pages → Deploy from branch → main → /(root).
